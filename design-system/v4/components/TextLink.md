TextLink is an inline navigation link inside running text.

**Consumer provides:** `href`, `children`, `external` (adds icon + “se abre en una pestaña nueva”), `quiet` (body colour, for secondary links such as “¿Olvidaste tu contraseña?”).

**Rules:** colour `accent-text` (gold-800 on light, gold-300 on dark), always underlined — colour alone doesn't identify a link. Never use `accent` gold for link text. Link text says where it goes (“Política de cookies”), never “aquí”.

**Replaces:** ad-hoc `text-avocat-gold hover:underline` links (2.91:1 on cream).

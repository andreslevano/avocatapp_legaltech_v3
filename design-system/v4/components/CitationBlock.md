CitationBlock lists the sources behind an answer: number, title, reference (ECLI / BOE), optional quote, verification status, link.

**Rules**
- Every legal claim in an answer carries a superscript number linking to its source here.
- **Verification is explicit:** “Localizada” only when the reference resolved against an authoritative index (CENDOJ, BOE); otherwise “No localizada” in `warning-text`, and the export flow blocks un-verified citations by default. LLMs fabricate case citations; this is the UI's main defence.
- Quotes are set in EB Garamond italic to mark them as source text, not model text.
- The home page claims “Jurisprudencia real — cita sentencias del TS, AP y TC”: this component is what makes that claim checkable.
